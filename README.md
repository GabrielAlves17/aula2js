# JavaScript: DOM e coleções

Exercícios dos meus estudos de JavaScript, com manipulação da página e prática com arrays.

## Conteúdo

Em [`js.2/script.js`](js.2/script.js), experimento seleção e criação de elementos HTML, atributos, estilos, eventos de clique e métodos de arrays como `push`, `pop`, `filter`, `map`, `forEach` e `sort`.

## Como explorar

Abra [`js.2/index.html`](js.2/index.html) no navegador e acompanhe as interações e mensagens no console das ferramentas de desenvolvedor.

> Este é um caderno de exercícios. Alguns trechos são experimentais e ainda estão em evolução.
